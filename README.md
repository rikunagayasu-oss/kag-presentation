# Kansai Aquarium Guild — 関西水族館ギルド構想

水族館は、日本の宝。
もっと輝く場所にしたい。
そのために、水族館同士で協力し合うことが、重要だ。

---

## このリポジトリについて

関西水族館ギルド構想（KAG）のビジョンを共有するための、スクロール型プレゼンテーション資料です。

**公開URL**: [https://rikunagayasu-oss.github.io/kag-presentation/](https://rikunagayasu-oss.github.io/kag-presentation/)

## 中心思想

**水族館同士は、競合ではなく、仲間である。**

経営不振で貴重な生体が観られなくなることは、その館だけの損失ではなく、日本全体の文化的損失です。
一館だけで戦うのではなく、業界全体で本質的価値を高め続けるループを作る。

## 構想の中核

1. **共通年パス** — 関西の水族館を、一枚で巡る
2. **コンプ図鑑** — 御朱印帳に着想を得た、自分だけの一冊が育つ紙の図鑑
3. **アプリ（黒子）** — 鑑賞時間を奪わず、来館前後を豊かにする

## 議論のための初稿

この資料は、第一回の食事会で参加水族館の経営層と共有するための議論ドラフトです。
完成された企画ではなく、皆さんと一緒に育てていく妄想として持ってきました。
